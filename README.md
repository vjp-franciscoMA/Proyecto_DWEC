# Recetario


## ¿Qué hará la aplicación?


La aplicación permitirá gestionar un recetario de cocina.
Se podrán guardar y consultar diferentes recetas con sus datos principales.


## Campos de cada receta


Cada receta tendrá los siguientes campos:


- ID
- Nombre
- Categoría
- Tiempo
- Dificultad
- Raciones
- Fecha de la última vez


## ¿Cómo se ejecuta?


Para ejecutar la aplicación, abrir el archivo `index.html` en un navegador web.


Los datos de ejemplo se encuentran en el archivo `js/app.js`.
